## Template tips (delete before import)

- `## Module N: …` headings drive section splitting.
- `**Key Insight:**` / `**Key Point:**` → callout blocks.
- `**Q1 (Single choice)**` with `*(correct)*` → multiple choice.
- `**Front:**` / `**Back:**` under Flashcards → dialog cards.
- `> **Reflection: …**` → reflection interaction.
- YouTube links → video embed blocks.
- Vault images (`![[file.png]]`) are not imported in v1; use remote `https://` image URLs if needed.
- Strip internal “Version note” sections before sharing, or leave a `## Version note` heading — import drops everything from that heading onward.
